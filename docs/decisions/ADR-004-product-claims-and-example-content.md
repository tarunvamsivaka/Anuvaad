# ADR-004: Evidence-led Product Copy and Examples

**Date:** October 2026
**Status:** Accepted

## Context

The landing page mixed working product interactions with illustrative PR flows, static benchmark tables, simulated telemetry, anonymous testimonials, and claims about uptime, certifications, and retention. This made it hard to tell what a user could verify in the product.

## Decision

- Describe current application behavior in product copy and link to the privacy page for processing details.
- Label static demos as examples, and do not make their simulated values look like live measurements.
- Publish customer quotes, adoption figures, performance claims, uptime, and certifications only when a reviewer can link them to dated evidence.
- Keep the language explorer focused on language examples until benchmark data has a reproducible methodology and source.
- Prefer specific interface language and durable visual rules over invented status labels, versions, and infrastructure telemetry.

## Consequences

Some marketing sections are less expansive, but the application makes fewer claims than users cannot validate. When verified evidence becomes available, a dated source and methodology can support restoring a metric or testimonial.
