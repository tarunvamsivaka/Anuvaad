## 2024-09-16 - OutputPanel & BlockCard re-renders
**Learning:** In the codebase's memory, I saw: "Frontend components rendering code blocks (e.g., BlockCard within OutputPanel) are computationally expensive due to Monaco editors and Framer Motion animations. Always use memoization (React.memo) for these list items to prevent UI lag. Crucially, avoid inline functions (including wrapping callbacks in arrow functions during render, e.g., onEdit={(val) => handle(idx, val)}) or state-dependent useCallback hooks, as these break memoization. Pass stable function references directly using functional state updates (setState(prev => ...)) and modify child components to accept and pass back necessary context like index." I found that `BlockCard` is not memoized and `OutputPanel` creates an inline arrow function for `onEditBlock` for every block map iteration.
**Action:** Use `React.memo` for `BlockCard` and update `OutputPanel` and `BlockCard` to pass `index` and avoid inline functions.
