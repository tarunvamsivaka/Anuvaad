## 2024-05-18 - [React.memo Stale Closure Risk]
**Learning:** When using `React.memo` with a custom equality function, ensure all props (including callback functions) are properly accounted for, or you risk introducing stale closures. Furthermore, if a callback like `onEditBlock` is defined inline in the parent component and needs to access state (like `outputBlocks`), it will be a new reference on every render. To properly memoize the child component, the callback must be wrapped in `useCallback` in the parent and passed as a stable reference.
**Action:** Always prefer shallow equality (default) for `React.memo` unless strictly necessary. When passing callbacks to memoized components, ensure they are wrapped in `useCallback` in the parent, with correct dependency arrays.
