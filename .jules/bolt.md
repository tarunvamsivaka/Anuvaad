## 2024-05-14 - Initial Learnings
**Learning:** React memory instructions explicitly say: "Frontend components rendering code blocks (e.g., `BlockCard` within `OutputPanel`) are computationally expensive due to Monaco editors and Framer Motion animations. Always use memoization (`React.memo`) for these list items to prevent UI lag. Crucially, avoid inline functions (including wrapping callbacks in arrow functions during render, e.g., `onEdit={(val) => handle(idx, val)}`) or state-dependent `useCallback` hooks, as these break memoization. Pass stable function references directly using functional state updates (`setState(prev => ...)`) and modify child components to accept and pass back necessary context like `index`."
**Action:** Need to modify `BlockCard` to accept `index` in the `onEditBlock` callback and wrap it in `React.memo`. `OutputPanel` needs a stable, `useCallback`-wrapped `handleEditBlock` that uses functional state updates.
