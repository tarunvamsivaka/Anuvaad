## 2026-10-04 - [React Memoization with Zustand]
**Learning:** React components subscribing to Zustand stores without specific selectors or `useShallow` will re-render on any store update. When dealing with computationally expensive components like `BlockCard` (containing Monaco editors and Framer Motion animations) inside a mapping list, these unnecessary re-renders cause severe UI lag, especially during streaming where state updates rapidly.
**Action:** Always wrap list items in `React.memo`. Crucially, avoid passing inline functions or state-dependent `useCallback` hooks down as props, as these break memoization. Pass stable function references using functional state updates (`setState(prev => ...)`). Also, use `useShallow` when subscribing to multiple state variables in Zustand.
