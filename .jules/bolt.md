## 2024-05-21 - [Memoizing BlockCard in OutputPanel]\n**Learning:** The frontend lists of computationally expensive code block components (due to Monaco editors or animations) can cause UI lag if not memoized. When applying React.memo to items in a list mapped from state, passing inline functions (like 'onEditBlock') breaks memoization on every render.\n**Action:** Use functional state updates (setState(prev => ...)) to define a single, stable callback function wrapped in useCallback, and pass child indices to that callback, avoiding inline closures. Additionally, typing state setter props as '(action: React.SetStateAction<T>) => void' enables functional updates without cascading strict type errors from custom hooks.
