
## 2024-05-30 - [Memoizing expensive BlockCard]
**Learning:** I noticed that the frontend components rendering code blocks (e.g., BlockCard within OutputPanel) are computationally expensive and not memoized. In the memory instructions, it states: 'Frontend components rendering code blocks (e.g., `BlockCard` within `OutputPanel`) are computationally expensive due to Monaco editors and Framer Motion animations. Always use memoization (`React.memo`) for these list items to prevent UI lag during state updates or SSE streaming. Crucially, avoid inline functions or state-dependent `useCallback` hooks that break memoization; instead, pass stable function references using functional state updates (`setState(prev => ...)`) and have child components handle their own indices.'
**Action:** Use `React.memo` on `BlockCard`, change `onEditBlock` to pass the index and the new text, and ensure `setOutputBlocks` supports functional updates if we want to avoid re-renders when modifying a block.
