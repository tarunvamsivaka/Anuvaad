## 2023-10-27 - [Add React.memo to BlockCard]
**Learning:** Found that `BlockCard` components within `OutputPanel` are re-rendered unnecessarily as translations stream in and elements update state. `OutputPanel` iterates over translation blocks map using `outputBlocks.map((block, idx) => <BlockCard />)`. These block cards are computationally complex (involve Monaco editors or Framer Motion animations) and modifying a single English translation block updates the full `outputBlocks` array in the parent hook, re-rendering all other unmodified blocks.
**Action:** Wrapped `BlockCard` in `React.memo` so they only re-render if their explicit props (the specific block object they receive, its index, or `onEditBlock` reference) change. This provides a measurable frontend performance improvement during long list translation streaming.
