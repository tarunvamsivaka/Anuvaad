## 2024-05-18 - [Optimizing List Item Renders with React.memo and Stable Callbacks]
**Learning:** When trying to memoize computationally expensive list items (like `BlockCard` containing Monaco editors and Framer Motion animations), simply wrapping the component in `React.memo` is insufficient if the parent passes an inline function (e.g., `onEdit={(val) => handle(idx, val)}`) or a state-dependent callback. These break memoization because a new function reference is created on every render.
**Action:** To correctly memoize list items, refactor the child component to accept the necessary context (like `index`) and pass it back through the callback. In the parent, define a stable callback using `useCallback` coupled with a functional state update (`setState(prev => ...)`). This ensures the function reference remains stable across renders, allowing `React.memo` to effectively prevent unnecessary re-renders.
