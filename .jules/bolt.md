## 2026-09-14 - BlockCard Memoization Insight\n**Learning:** Components rendering code blocks and translations like `BlockCard` are rendered inside a list (`OutputPanel`) that updates frequently due to SSE streaming and state changes. Missing memoization here is a significant bottleneck because React reconciles the entire list on every parent re-render, leading to lag during updates.\n**Action:** Apply `React.memo` to `BlockCard` and ensure any props passed from the parent (like `onEditBlock`) are stable (e.g., using functional state updates or `useCallback`) to prevent unnecessary re-renders.
